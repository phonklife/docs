<Info>
  **Prerequisites**:
  - Node.js installed
  - The Mintlify CLI available locally
</Info>

Use this page when you need to preview or validate changes to the documentation repository itself.

<Steps>
<Step title="Install the Mintlify CLI">

```bash
npm i -g mint
```
</Step>

<Step title="Start the local preview">

From the repository root, run:

```bash
mint dev
```

A local preview will be available at `http://localhost:3000`.

</Step>
</Steps>

## Validate links

Run this command before you finish documentation changes:

```bash
mint broken-links
```

## Navigation updates

Pages do not appear in the sidebar automatically. When you add, remove, or rename a page, update `docs.json` to keep navigation accurate.

## Contributor checklist

- Preview the updated page locally
- Check headings, callouts, and code blocks in the rendered site
- Verify new links and cross-links
- Keep terminology aligned with `AGENTS.md`
- Remove placeholder or starter content instead of leaving it hidden

## Troubleshooting

- If `mint dev` fails to start, reinstall the CLI with `npm i -g mint`
- If a page renders as `404`, confirm the file path matches the entry in `docs.json`
- If preview content looks stale, restart `mint dev`
